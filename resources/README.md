# Resources

- `chime.wav`: generated in this repo by `scripts/make-chime.mjs` (two soft sine tones, no third-party audio, so no external licence). Regenerate with `node scripts/make-chime.mjs`.
- `tray.png` / `tray@2x.png`: tray icon (22x22 and 44x44), generated by `scripts/make-tray-icon.mjs` (a door glyph, white with a dark outline so it works on light and dark panels; Node built-ins only). Regenerate with `node scripts/make-tray-icon.mjs`.
- `deskknock.desktop`: desktop entry template shipped with the .deb (used by Task 11); the runtime autostart file is written by `src/main/autostart.ts`.
